Ignis is a Flutter game engine built on nodes and signals.

These docs are under construction. They exist to do the one thing the README cannot: run.

## Two lanes

**Usage** is for building a game: what to construct, what to call, what rule to follow. **Internals** is for how the engine works and why it was built that way. The same subsystem shows up in both, at different altitudes.
